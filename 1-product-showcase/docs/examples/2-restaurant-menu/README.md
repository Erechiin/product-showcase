**Em preparação.** Este repositório reserva uma próxima atividade da coleção
Jonathan Sales Programming. O nome é provisório e pode ser alterado pelo professor.

## Antes da liberação

O professor preencherá este README com:

- Objetivo, pré-requisitos e preparação anterior à aula.
- Explicação breve das ferramentas.
- Comandos de instalação e execução.
- Roteiro com ações pequenas, arquivos a abrir e resultados esperados.
- Pausas para a turma conferir cada etapa antes de avançar.
- Primeiras mudanças de frontend para fazer em conjunto.
- Detalhes para terminar individualmente e desafios opcionais.
- Verificações e critérios de entrega.

A organização e o ciclo de trabalho serão parecidos com os da atividade 1.
As regras específicas serão apresentadas no novo guia. O texto de orientação
ficará em português; código, comentários, interface e arquivos ficarão em inglês.

## Quando estiver disponível

Cada aluno fará fork deste repositório para sua conta, poderá escolher um nome
como `2-my-menu` e clonará sua cópia em uma pasta própria. A turma seguirá o
mesmo roteiro, mantendo a lógica comum. Extensões serão escolhas para depois.

Os comandos específicos serão incluídos aqui quando a implementação estiver
pronta. O resultado de cada pessoa ficará no próprio fork.
