# Workspace instructions

- This `projects` workspace is a local collection, not a single application or
  Git repository. Keep each activity inside its own numbered project directory.
- The first starter is `1-product-showcase/`. Future activities belong beside
  it, not inside it. Do not place application files or a shared virtual
  environment at the workspace root.
- Read the selected project's AGENTS.md before editing it. Run its commands
  from that project's directory; create a separate .venv for each activity.
- Use English for code, comments, UI text, filenames, repository names, and
  executable examples. Write README files and human-facing guides in Brazilian
  Portuguese. Keep agent instructions in English.
- Preserve individual repositories and forks. Do not initialize Git at this
  collection root or publish, configure remotes, or push without a request.
- Keep the shared teaching sequence and simple logic across projects. Future
  activity placeholders must be clearly marked as unavailable.
- First project: `cd .\1-product-showcase`.
- Run there: `.\.venv\Scripts\python.exe -m flask --app app run --debug`.
- Verify there: `.\.venv\Scripts\python.exe verify.py`.
