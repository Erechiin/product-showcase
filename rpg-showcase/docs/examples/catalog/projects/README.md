# Atividades

> Preparação do catálogo: substitua `YOUR_USERNAME` nos links pela conta do
> professor e confira os endereços antes de publicar esta lista.

| Número | Atividade | Situação | Esqueleto para fork | Versão do professor |
| --- | --- | --- | --- | --- |
| 1 | My Showcase | Esqueleto pronto; publicar no GitHub | [1-product-showcase](https://github.com/YOUR_USERNAME/1-product-showcase) | Adicionar link quando publicada |
| 2 | Restaurant Menu — nome provisório | Em preparação | Aguardar liberação | A definir |

1. Depois de publicar e conferir o esqueleto 1, marque-o como **Disponível**.
2. Para cada nova atividade, acrescente uma linha com seu número, nome genérico,
   situação e link do repositório próprio.
3. Mantenha atividades futuras **Em preparação** até terem código funcional e
   roteiro detalhado com pontos de conferência.

O link da versão do professor mostra um exemplo de personalização.
Para a atividade, abra o **esqueleto**, faça seu fork e escolha um nome como
`1-book-store`. Siga o README em português, execute as etapas em conjunto e
continue os detalhes depois. Código e textos da interface permanecem em inglês.
